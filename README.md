An entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on [make.fun](https://make.fun).

`main.py` writes one line — the museum label a museum in the year 3000
places next to an ordinary object from today — to `/output/entry.txt`:

> Group Chat, c. 2024. Each night, humans gathered here to share pictures of food and argue, in writing, about where to eat. They never decided.

Run it with `python3 main.py`. The output is a single line, 142 characters, valid UTF-8.
